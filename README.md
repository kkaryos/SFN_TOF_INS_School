# Getting started on VISA Jupyter

Follow these steps to use the **SFN TOF INS School** notebooks on VISA.

## 1. Open a terminal

In JupyterLab, open a **Terminal** from the Launcher.

## 2. Download the exercises

```bash
git clone https://github.com/kkaryos/SFN_TOF_INS_School.git
cd SFN_TOF_INS_School
```


## 3. Install everything

```bash
bash setup_sfn_school_visa_v2.sh
```

This installs the required software and adds the **Python (mcstas)** Jupyter kernel.

## 4. Start the exercises

In the JupyterLab file browser, open `SFN_TOF_INS_School` and double-click:

**`indirect_geometry_spectrometer_student_workbook.ipynb`**

Select **Python (mcstas)** in the notebook's kernel menu (top right). Run cells with **Shift + Enter**.

You can also open `reduce_powder.ipynb` for the data-reduction exercises.
